MediumClass 安装与测试说明（普通玩家版）

更新：2026-09-24。照着点按钮即可，不需要编程经验。

当前进度：还没有编译好的维护版安装包。 之前约 257 KB 的 MediumClass-maintenance-2026-09-23.zip 是源码，直接交给 UMM 会报找不到 MediumClass.dll。目前请先完成下面的“一、二、三”，把参考文件交给维护者。

一、找到正确的游戏目录

1. 完全退出游戏。
2. 在 Steam 库里右键《Pathfinder: Wrath of the Righteous》→“管理”→“浏览本地文件”。
3. 打开的文件夹里应该能看到 Wrath_Data。就选这个文件夹，不要进入 Wrath_Data。

例如本次用户的游戏目录是：

D:\steam\steamapps\common\Pathfinder Second Adventure

别人的盘符和前面几级文件夹可能不同，以自己电脑为准。当前测试目标为游戏 2.7.0x。

二、先装好三个前置

如果已经装好这些前置，就核对版本后跳到第三部分。

如果之前把源码包装进过 UMM，先关闭游戏，把游戏 Mods 中的 Medium Class 或 MediumClass 文件夹移到桌面备份。不要留在 Mods 内只改名字；否则检查前置时还会看到旧的缺 DLL 报错。没有这些文件夹就跳过。

1. Unity Mod Manager（简称 UMM）0.33.0

- Nexus 下载页：https://www.nexusmods.com/site/mods/21?tab=files
- Nexus 验证过不去时，用 作者提供的 Dropbox 备用下载：https://www.dropbox.com/s/wz8x8e4onjdfdbm/UnityModManager.zip?dl=1。该地址来自作者 GitHub README；下载后确认实际显示版本，备用包的版本未独立核验。

下载 ZIP 后先解压，打开 UnityModManager.exe。在 Game/游戏下拉框选择 Pathfinder: Wrath of the Righteous，不要选 Kingmaker。Folder/目录选第一部分找到的游戏主目录，点击 Install/安装。已有安装时先核对显示的版本与路径；不需要反复点击卸载。

2. ModMenu 2.0.14

直接下载 ModMenu-2.0.14.zip：https://github.com/CasDragon/ModMenu/releases/download/2.0.14/ModMenu-2.0.14.zip

备用：打开发布页：https://github.com/CasDragon/ModMenu/releases/tag/2.0.14，展开 Assets，选 ModMenu-2.0.14.zip。不要选 Source code。

3. TabletopTweaks-Core 0.7.14a

直接下载 TabletopTweaks-Core.zip：https://github.com/Vek17/TabletopTweaks-Core/releases/download/v0.7.14/TabletopTweaks-Core.zip

备用：打开发布页：https://github.com/Vek17/TabletopTweaks-Core/releases/tag/v0.7.14，展开 Assets，选 TabletopTweaks-Core.zip。网页标签是 v0.7.14，当前发行名称为 0.7.14a。不要选 Source code。这里只需要 Core，不要求再安装 TabletopTweaks-Base。

把两个依赖装进 UMM

1. 回到 UnityModManager.exe，切到 Mods 页。
2. 将刚下载的 ModMenu 和 TabletopTweaks-Core 两个 ZIP 拖到安装区域，逐个等待完成。这两个包通常不需要自己解压。
3. 启动游戏，到主菜单后按 Ctrl＋F10 打开游戏内 UMM；如改过热键，以自己设置为准。
4. 确认 ModMenu、Tabletop Tweaks Core 都正常启用，没有红色“!!!”。然后退出游戏。

BlueprintCore 不用你单独下载或安装。 它由维护者在编译 MediumClass 时合并进去。玩家也不用安装 Visual Studio、Python 或 Git。

三、把构建参考文件交给维护者（现在执行）

1. 把“玩家说明与收集工具”ZIP 完整解压到桌面或下载目录中的一个新文件夹。不要在压缩软件的预览窗口里直接运行。
2. 保留旁边的 scripts 文件夹，双击 02-双击收集构建文件.cmd。
3. 如果弹出选目录窗口，选择第一部分的游戏主目录。如果自动找到目录，核对窗口打印的路径。
4. 等待完成。生成的文件叫 MediumClass-build-references-日期时间-编号.zip，在 scripts 文件夹 中；窗口也会显示完整位置。
5. 把这个新 ZIP 发给维护者。它包含编译参考文件，不包含存档；文件比源码包大很多是正常的。

如果你用的是旧收集小包，双击的入口叫 Collect-BuildReferences.cmd，生成 ZIP 在同一文件夹里；作用相同，不用重复收集两份。

到这里就可以停下。 维护者收到文件后处理编译。生成的参考 ZIP 不要导入 UMM，也不要上传到公开 GitHub。收集失败时按后面的报错表处理。

四、拿到编译好的安装包后（以后再执行）

只有维护者明确给出“UMM 安装包”时才做这部分。不要把源码 ZIP、说明工具 ZIP 或参考文件 ZIP 当成安装包。

1. 关闭游戏。若之前装过 Medium，先把游戏 Mods 里原来的 Medium Class 或 MediumClass 文件夹整体移到 Mods 之外备份。两个名字都要留意。只处理 Medium，不移动其他 Mod；不要仅在 Mods 内改成“备份”名字。
2. 打开 UMM 的 Mods 页，把维护者给的安装 ZIP 拖入安装。普通玩家不需要找 DLL、手动合并或复制源码。
3. 安装后，Medium 的文件夹内应该有 MediumClass.dll、Info.json、mediumclass_assets 三个文件；最后一个是文件，不是文件夹。看不到扩展名时，在资源管理器勾选“文件扩展名”。
4. 启动游戏到主菜单，Ctrl＋F10 查看 Medium 是否正常启用。红色“!!!”、卡住或崩溃时停止后续测试，按第六部分发日志。

如果 UMM 显示两条 Medium，说明可能装了两份。关闭游戏，把两份的位置截图发给维护者，不要同时启用。

五、第一次只做这几项测试

先用新建测试角色，不加载唯一的重要旧档。按顺序做；前一步失败就停下。

1. 启动： 能否到主菜单，UMM 中 Medium 是否正常启用。
2. 建角： 能否选到 Medium，职业选项是否重复。
3. 通灵： 选择一个灵体，记录选了哪个，看能力有没有出现。
4. 存读： 另存为测试档，完全退出游戏，再启动读取，检查灵体和能力是否还在。
5. 休息与换灵体： 休息后再通灵，观察旧能力是否残留、加值是否重复。

拍下角色等级、灵体名称和异常界面即可，不需要自己判断骰子或加值公式。高等级、双 Medium、洗点和旧档测试由维护者安排；旧档需要先备份。

六、报错时怎么处理

- 找不到 Mods 路径： 常见于刚装好游戏，还没完成第二部分。先用 UMM 安装 ModMenu 和 TTT-Core；不要只创建一个空 Mods 文件夹。
- Expected one installed ModMenu / TabletopTweaks-Core： 依赖没装到所选游戏、装错了源码包，或者同一依赖有两份。发 UMM 的 Mods 页截图和报错窗口。
- 找不到 UnityModManager.dll / 0Harmony.dll： UMM 还没有正确安装到所选游戏，或安装位置与工具预期不同。发 UMM 安装页截图，不要从其他游戏复制 DLL。
- MediumClass.dll not found： Medium 文件夹缺少编译后的 DLL。常见于把源码包导入 UMM；等待维护者提供安装包。
- 红色“!!!”但没有更多说明： 这个标记只表示加载报错，按下面步骤找日志。
- 脚本被安全策略阻止： 发完整提示，不要自己修改电脑的组织安全策略。

找日志

1. 游戏内 Ctrl＋F10 → 顶部 Logs 页，截图包含 Medium Class/MediumClass 的第一段报错及后面几行。
2. 点击底部 Open detailed log，把打开的完整日志文件发给维护者。
3. 按钮打不开时，在 Windows 资源管理器地址栏粘贴以下路径，找 Player.log：

%USERPROFILE%\AppData\LocalLow\Owlcat Games\Pathfinder Wrath Of The Righteous

在刚出现问题后就复制日志，下次启动可能覆盖它。再附上 UMM 的 Mods 页截图，按照 03-报错反馈模板.txt 写两句操作过程即可。

恢复原来的游戏环境

关闭游戏，把本次测试的 Medium 文件夹移出 Mods；如果之前备份过旧版本，恢复备份。使用原来的未覆盖存档。不要只把测试文件夹在 Mods 内改名。

目前尚未验证游戏和旧档兼容性；能到主菜单也不等于全部职业能力已经测过。
