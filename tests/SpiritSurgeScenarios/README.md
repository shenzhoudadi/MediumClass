# Spirit Surge regression scenarios

Runs the actual production `MediumSpiritSurgeComponent` and dice rules on explicit game API doubles. A deterministic maximum die checks self versus ally Orders, Medium versus Prowler, multiple active spirits, Hardened Soul, concentration, cleanup and Legendary Marshal's fixed die. This does not run Unity or an actual save.

Run `dotnet run --project tests/SpiritSurgeScenarios/SpiritSurgeScenarios.csproj` on Windows (.NET Framework 4.7.2).
